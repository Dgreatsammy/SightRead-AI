## Goal

Add a focused practice mode for musicians learning to sight-read sheet music.

## Features

### 1. Practice speed

Add selectable playback speeds:

* 25%
* 50%
* 75%
* 100%

The selected speed must change actual note timing, not merely change a label.

The existing BPM control must continue working.

## 2. Count-in

Add a count-in option:

* Off
* 1 bar
* 2 bars

Before the selected playback range begins, play audible metronome counts.

The count-in must not alter the musical timing of the score.

## 3. Metronome

Add:

* Metronome on/off
* Strong first beat
* Weaker remaining beats
* Tempo synchronized with playback

Do not create a fake visual-only metronome.

## 4. Volume and mute

Add:

* Master volume control
* Mute button
* Accessible labels
* Safe default volume

All audio must pass through a master gain control.

## 5. Practice loop

Improve the existing loop controls:

* Selected start measure
* Selected end measure
* Loop enabled/disabled
* Current loop count
* Clear visual indication of the active loop

The loop must restart at the selected start measure and stop at the selected end measure.

## 6. Visual synchronization

Synchronize the interface with playback:

* Current measure
* Current note when reliable
* Playback progress
* Count-in state
* Loop state

If exact note highlighting is unreliable, highlight the current measure instead of displaying incorrect note highlighting.

## 7. Local practice settings

Use local browser storage only for:

* Last selected tempo
* Last playback speed
* Metronome preference
* Volume
* Last selected measure range

Do not add:

* Backend
* Database
* Login
* Payments
* Cloud sync
* Analytics

Imported MusicXML files do not need to be permanently stored in this version.

## 8. MusicXML safety

Do not claim support for advanced notation features unless the parser handles them correctly.

Gracefully handle:

* Empty scores
* Missing pitch
* Rests
* Unsupported structures
* Invalid durations
* Invalid MusicXML
* Scores with multiple parts

Do not silently play incorrect notes.
