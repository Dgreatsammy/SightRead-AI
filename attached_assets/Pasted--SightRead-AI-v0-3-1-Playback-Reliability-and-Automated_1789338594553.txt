## Code quality

* Keep parser logic separate from UI.
* Keep audio scheduling separate from React rendering.
* Avoid real-time delays in unit tests.
* Use fake timers or deterministic clock injection where appropriate.
* Do not create uncontrolled intervals or timers.
* Do not weaken validation merely to make tests pass.
* Do not add fake test assertions.
* Do not test only that functions exist; test actual returned values and state transitions.
